# Лабораторная работа №4
**Тема: Обработка естественного языка (NLP) и классификация текстовых данных с помощью нейронных сетей.**

## Задачи

### 1. Классификация писателей: подбор гиперпараметров (Lite)
Разработали 9 различных конфигураций нейронных сетей для распознавания текстов классиков с целью поиска оптимальных настроек предобработки.
- **Параметры токенизации:** варьирование размера словаря (**10 000 – 20 000**), ширины окна (**1000 – 2000**) и шага (**100 – 500**).
- **Архитектура:** модель прямого распространения **Sequential**, полносвязные слои **Dense**, а также слои **Dropout** и **BatchNormalization**.
- **Результат:** проведен сравнительный анализ точности моделей по показателю **val_accuracy** для выявления наиболее эффективной комбинации параметров.

### 2. Анализ тональности отзывов Tesla (Pro)
Реализовали нейронную сеть для бинарной классификации мнений пользователей на основе текстовых файлов с позитивными и негативными отзывами.
- **Задача:** достижение точности работы модели в диапазоне **85-90%** на проверочной выборке.
- **Особенности:** особое внимание уделено балансировке базы (равное количество примеров каждого класса) для корректного обучения.
- **Результат:** целевой порог точности успешно преодолен, модель стабильно распознает эмоциональную окраску коротких сообщений.

### 3. Распознавание 20 российских писателей (Ultra Pro)
Создали масштабную систему классификации, охватывающую произведения 20 различных авторов, что потребовало работы с расширенной базой данных.
- **Методы:** сравнительное использование подходов **Bag of Words** (мешок слов) и слоев **Embedding** (векторные представления).
- **Особенности:** автоматизированная разбивка данных с помощью циклов; объем проверочной выборки составил **20%** от общей базы.
- **Результат:** точность распознавания составила **не ниже 95%** для модели Bag of Words и **75-80%** для модели со слоями Embedding.
